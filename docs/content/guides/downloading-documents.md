## Choose a format

Open the **Download** menu, the download icon at the top-right of a Markdown document or file viewer. The native menu works with a keyboard,
on mobile screens, and without JavaScript. Directory listings do not have a download menu.

Markdown documents offer:

- **Markdown** for the current, unmodified source, including any byte-order mark and front matter;
- **PDF** for a simplified, self-contained document generated by Mavis;
- **DOCX** when pandoc was found in `PATH` at startup and DOCX export is enabled.

Other viewer-supported files offer a **Raw file** attachment. **View raw file** remains a separate inline action.

The equivalent URLs are `?download=markdown`, `?download=pdf`, `?download=docx`, and `?raw=1&download=1`. Downloads read
current content on every request, so repeating a download after an edit does not require a restart.

## PDF export

PDF generation is built into Mavis. It does not invoke pandoc, Python, WeasyPrint, a browser, Ghostscript, or an external
service, and it makes no network or font requests. Mavis embeds Roboto and Roboto Mono in the application and in the
resulting PDF.

PDF export removes front matter and represents common Markdown text, headings, emphasis, lists, tables, links, code, and
eligible local PNG, JPEG, and GIF images. Layout is intentionally simplified rather than browser-identical.

Unsupported images, including SVG, and rasters above 8,388,608 pixels appear as a **Preview unavailable** placeholder. Characters unavailable in the
embedded fonts, including emoji and CJK text, appear as visible replacement glyphs rather than disappearing. Mavis does
not claim SVG rendering, emoji or CJK coverage, PDF/A compliance, or exact HTML/CSS fidelity.

## DOCX export

Mavis checks for `pandoc` in `PATH` once at startup. When found, DOCX is enabled automatically unless `export_docx = false`.
To select a different installation, use the service's `PATH` or a symlink named `pandoc` on that path.
See [Downloads configuration](../reference/configuration.md#downloads).

DOCX conversion uses sanitized article HTML without navigation, search, front-matter panels, the table of contents, or
other interface elements. Eligible local images are embedded before conversion. Mavis does not fetch remote images or
give pandoc access to arbitrary source files. Pandoc runs locally with `--sandbox`; document content is never sent to an
external conversion service.

## Content boundaries and limits

Every format applies the same hidden-file, exclusion, root-confinement, symlink, and `.mavis.conf` privacy rules as normal
content requests. Unauthorized embedded images are omitted or visibly replaced without exposing their bytes.

Generated PDF and DOCX exports have these limits:

| Limit | Value |
| --- | ---: |
| Markdown source | 10 MiB |
| Generated attachment | 50 MiB |
| Conversion time | 30 seconds |
| Concurrent PDF/DOCX conversions | 2 shared workers |

Original Markdown and raw downloads are not generated conversions and do not use the 10 MiB source limit. Mavis returns
an attachment only after conversion and validation complete; failures do not return partial output, temporary paths, or
process diagnostics.
